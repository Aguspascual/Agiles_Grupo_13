En HU-04, las reglas semanales generan disponibilidad para una fecha consultada y solo se guardan reservas o bloqueos excepcionales; la persistencia compartida, las APIs y las autorizaciones efectivas siguen pendientes de backend. El tablero de Trello conserva las historias y sus checklists separan responsabilidades frontend/backend.
